        🤖 About Bob

        Bob is a browser-based programming assistant and learning project.

        Features

        • Chat with quick responses
        • Calculator, date/time and converter
        • Memory, notes and To-Do list
        • Number Guessing and 5-round Rock Paper Scissors
        • Programming reference with search

        Manual languages

        Python, C, C++, Java, JavaScript, HTML and CSS.

        The manual is an original practical reference, not a copy of official specifications.
